# 🎵 Looper Player v1.0.0-beta.2 (Desktop Release)

We are pleased to announce the second beta release of **Looper Player** (`v1.0.0-beta.2`), featuring an intelligent Quick Picks recommendation overhaul, queue switching auto-focus, universal control polish, mini-player refinements, and major stability and lifecycle improvements.

---

## ✨ What's New in v1.0.0-beta.2

### 🎲 Quick Picks Recommendation Overhaul
* **Randomized Top Songs Pool**: Top played tracks are no longer chosen in strict, predictable 1–6 rank order. Looper now draws and shuffles from an expanded pool of up to 50 top played tracks, allowing less-played favorites (ranks 6–40) to be discovered alongside top tracks.
* **Dedicated Random Discovery Pool**: 50% of the quick picks slots on the homescreen are now drawn from a dedicated pool of random songs strictly outside your top songs, giving you an even richer mix of fresh discoveries every session.
* **Balanced 6-Slot Cycle**: Round-robin interleaved with top songs, random discovery, recently added, and favorites.

### 📋 Queue Page Auto-Scroll on Switch
* **Instant Song Centering**: When switching between saved queues using the dropdown queue switcher on the Queue page, the view automatically and smoothly scrolls to and centers the currently active song in the newly selected queue.

### 🎛️ Control Deck & Player Bar Polish
* **Universal Hover Glow & Hand Cursors**: Added subtle circular backdrop hover glow, hand pointer cursor, and hover brightening across all player bar control buttons (Shuffle, Repeat, Previous, Play/Pause, Next, Favorite, Lyrics, Queue, and Fullscreen).
* **Volume Button Tooltip**: Added hand cursor and explicit `"Mute"` / `"Unmute"` tooltip for the volume button across inline, anchor, and popup modes.

### 🪟 Mini-Player Polish & Bug Fixes
* **True Position Persistence**: Opening the queue drawer while the corner mini-player is at the bottom edge no longer causes the shifted-up coordinates to overwrite your saved resting corner position when closing or restoring to the normal player.
* **Vertical Alignment Centering**: Standardized corner mini-player collapsed height and centered the header row layout to eliminate top/bottom margin disparities and RenderFlex overflows.
* **Instrumental Gap Animation in Lyrics**: Empty lines and musical gaps in both standard and corner mini-player lyrics now render a beat-pulsing, bouncing music note icon ("♫"), matching fullscreen lyrics.

### 🛡️ Stability & Lifecycle Hardening
* **Defunct Lifecycle Error Guard**: Replaced Riverpod subscriptions inside rapid-cycling animated lyric glyphs with pure stateful widgets, eliminating `_lifecycleState != _ElementLifecycle.defunct` assertions during track skipping (`skipNext()`) and window focus blur transitions.
* **GlobalKey Lifecycle Cleanliness**: Dynamic lyric line GlobalKey caches are now systematically cleared between songs to eliminate key collisions across track transitions.
* **Context Menu Deduplication**: Consolidated default shell ProgID verb handlers to eliminate duplicate context menu entries on Windows desktop.

## 📦 Downloads & Installation

### 🪟 Windows (x64)
* **Installer (`Looper-Setup-x64.exe`)**: Easy setup wizard that installs to local user programs (no admin rights needed), creates desktop/start-menu shortcuts, and associates common audio formats (`.mp3`, `.flac`, `.wav`, `.m4a`, `.ogg`, `.opus`, `.aac`).
* **Portable (`looper-windows-x64-portable.zip`)**: Extract and launch `looper_player.exe` directly from any folder or USB drive with zero installation.

### 🐧 Linux (x86_64)
* **Debian / Ubuntu / Linux Mint**: Download and install `looper_1.0.0-beta.2_amd64.deb` (`sudo dpkg -i looper_*.deb`).
* **Fedora / RHEL / openSUSE**: Download and install `looper-1.0.0-beta.2.x86_64.rpm` (`sudo rpm -i looper-*.rpm`).
* **Universal AppImage**: Download `looper-1.0.0-beta.2-x86_64.AppImage`, run `chmod +x`, and execute anywhere.
* **Portable Tarball**: Download `looper-player-1.0.0-beta.2-linux-x64.tar.gz` and extract anywhere.

> [!NOTE]  
> **Linux Prerequisite**: Ensure `libmpv` is installed on your distribution:
> - Ubuntu/Debian: `sudo apt install libmpv-dev libmpv2`
> - Arch Linux: `sudo pacman -S mpv`
> - Fedora: `sudo dnf install mpv-libs`
